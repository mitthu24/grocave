## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deployment to Vercel
This repository is configured for zero-configuration instant deployment on Vercel:
```bash

npx vercel --prod
```
Or connect the repository on [vercel.com](https://vercel.com) with framework preset **Vite**.
